# ERINX Boxing: Neon Fight Night

A standalone arcade boxing game built with Pygame. Win two of three 45-second
rounds against the Iron Viper, or score a knockout.

## Run

From this directory, install the dependency and launch the game:

```powershell
python -m pip install -r requirements.txt
python main.py
```

## Controls

| Action | Keys |
| --- | --- |
| Move | A/D or Left/Right arrows |
| Jab | J or Z |
| Hook | K or X |
| Block | L or S |
| Dodge | Space or either Shift key |
| Pause / resume | Escape or Enter |
| Start / rematch | Enter (R also rematches) |
