# ERINX Python Games

A collection of four small, self-contained games built with Python and Pygame. Each game has its own source code, dependencies, and README with gameplay details.

## Games

| Game | Description | Project |
| --- | --- | --- |
| **Neon Fight Night** | Arcade boxing against an AI opponent | [`Game/ERINX_Boxing`](Game/ERINX_Boxing/) |
| **Little Harvest** | A cozy farming and crop-growing simulator | [`Game/ERINX_Farming_Simulator`](Game/ERINX_Farming_Simulator/) |
| **Echoes of the Grove** | A small action RPG set in a handcrafted forest | [`Game/ERINX_RPG_Adventure`](Game/ERINX_RPG_Adventure/) |
| **Starfall** | A neon arcade space shooter | [`Game/ERINX_Space_Shooter`](Game/ERINX_Space_Shooter/) |

## Requirements

- Python 3.10 or later
- Pygame 2.5 or later
- A desktop environment with a graphical display

Each game folder includes a `requirements.txt`. To run a game, open its folder in a terminal and run:

```powershell
python -m pip install -r requirements.txt
python main.py
```

On Windows, use `py` instead of `python` if that is the Python launcher installed on your system. See the game's README for controls, features, and troubleshooting.
